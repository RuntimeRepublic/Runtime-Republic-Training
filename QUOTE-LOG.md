# Quote Log

**Governed by:** CONTROL 09 — Doctrinal Foundations Standard, rule 14
**Status:** Draft. Started 2026-11-14 by Claude (Opus 5.5) for James Hodges. Nothing here is approved.

Every quotation a lesson uses is recorded here first, with its exact wording, its source and
a verification status. A lesson may only use a quote marked **Verified**.

## Status values

| Status | Meaning |
|---|---|
| Verified | Wording checked against the primary source on the date shown |
| Located | Primary source found; wording not yet checked |
| Flagged | A problem was found (wrong source, wording differs, date wrong). Not usable until fixed |
| Pending | Source not yet found |

## Rules (proposed)

1. Quote the primary source. A quote site or a secondary page is a lead, not a source.
2. One speaker, one exact wording, one source per row. If two sources disagree, record both
   and mark the row Flagged until the Human Engineer chooses.
3. Shorten only with an ellipsis (…); never change words. Punctuation follows the source.
4. Speakers are witnesses who agree, never authorities (CONTROL 09, rule 12).
5. Record where each quote is used, so a correction can be carried to every lesson.

University of Texas Reagan archive (reagan.utexas.edu), which no longer resolves. Those links
map to the Reagan Library's current pages using the same speech code:
`reagan.utexas.edu/archives/speeches/1981/72281a.htm` → `reaganlibrary.gov/research/speeches/72281a`.
