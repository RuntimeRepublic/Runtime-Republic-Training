# The Agentic Runtime Republic

A futuristic essay in ten parts by James Hodges, set on June 1, 2027. It imagines how
property-rights groups and legislators who work with a GitHub-connected AI, and coordinate
through X, Facebook, Discord and YouTube, move quickly toward the objectives of the
[AGCL Control Documents](https://github.com/RuntimeRepublic/AGCL-Control-Documents).

The scenes are imagined. The repositories, control documents and methods it names are real.
