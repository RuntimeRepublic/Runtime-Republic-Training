# The Agentic Civic Node

A six-part series written to be listened to. It names a new kind of civic group, the
Agentic Civic Node: one group of citizens, one cause, working in the open on GitHub, with
AI agents helping under human control. It covers starting a node, growing its rules with
PDCA, dividing past about seven members, specialty nodes, and the daily status that
carries lessons learned and best practices across the network.

Civic and non-partisan: it teaches a method, not any party's positions.
