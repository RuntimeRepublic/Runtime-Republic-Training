# Lean Civics Challenge

**Status:** Draft. One lesson so far; nothing here is approved.

Essays that invite existing groups to join the Lean Civics Challenge and onboard as an
org-level team. The challenge uses PDCA (Plan-Do-Check-Act) with three frameworks:
Moneyball, the British Bicycle Team (marginal gains) and the Close Encounters scale (CE1–CE5).
