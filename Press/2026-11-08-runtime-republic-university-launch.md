# Runtime Republic Launches Runtime Republic University: Free Courses in AI, GitHub and Discord for Citizens

**FOR IMMEDIATE RELEASE**

**SEDGWICK COUNTY, Kan. — November 8, 2026** — Runtime Republic, a civic-tech project, this weekend opened Runtime Republic University (RRU), a new GitHub organization building free courses in Claude AI, GitHub and Discord. RRU has completed and tested its first course, on Discord. It is not yet open to students.

## Who RRU is for

RRU is only for people who have never heard of Discord or GitHub, or who don't yet understand the power of using AI as a tool. No technical background is needed.

Runtime Republic is creating an agentic, assisted, asynchronous workflow. AI agents do the heavy lifting, an AI Guide assists each learner step by step, and everyone works on their own schedule. The goal is to help people work hard in life and overcome special interest groups.

## A university built in one day

On Sunday, November 8, RRU went from an empty GitHub organization to a working course skeleton in about six hours. Two repositories were created that morning:

- **rru-course** holds the course itself: the course map, lessons, quizzes, grading rubrics, research notes, and the instructions that turn a Claude Project, or any AI with a GitHub connector, into a personal instructor.
- **rru-traveler-template** is a public template each student copies into their own GitHub account to keep their learning record.

The work was done through five numbered work orders, with an AI agent handling the Git work and every change recorded in the repository history.

## How RRU teaches

RRU borrows from the factory floor. In manufacturing, a "traveler" is the work order that moves with a part and collects an inspection stamp at each station. At RRU, each student keeps a traveler repository. Every finished lesson earns a stamp, and a stamp only counts with evidence: a quiz score, a screenshot, a link or a commit. Gaps and rework are recorded honestly.

The course has three tracks, Claude AI (or any AI connected to GitHub), GitHub and Discord, and every student completes all three. A placement test sets each student's level (Foundation, Practitioner or Technologist), and the student's goal sets their path (Member, Organizer or Builder). Lessons are taught one skill at a time, beginner to expert, before moving to the next.

Each student's instructor is a Claude Project (or another AI connected to GitHub), which RRU calls "the Guide." The Guide teaches only from the course repository, grades open answers against a published rubric, writes the stamp, and checks on GitHub that the student committed it. Students are called "Hitchhikers," and the welcome line is a friendly "Don't panic."

## First course complete: Discord roles and permissions

RRU's first course, D1, teaches Discord server roles and permissions, starting from what a role is. It has been completed and tested, and its lessons are checked against Discord's own support articles. RRU is not ready for students yet; the course opens when the rest of the setup is in place.

## Learn at your own pace

There are no semesters and no deadlines. Each person learns at their own pace, one lesson at a time.

The whole point is to get people comfortable working together on a bill draft, or following a bill as it makes its way through the legislative process. Each tool has a job:

- **GitHub** is where you learn to use Claude AI as a study partner. In the Idea Zone, you think of something cool, and your AI Guide helps you build it while GitHub records your progress. GitHub also keeps the history of everything a group does on any project. New members get up to speed without long meetings or piles of reading: they simply chat in a thread with Grok, Claude, ChatGPT or any AI agent with a GitHub connection.
- **Discord** is the ultimate small-group organizer.

Plans are in the works for an iPhone app that sends notifications directly to your phone.
